# ☕ قهوه‌خانهٔ زر | Zar Coffee House

سایت فروش قهوه با طراحی لوکس، ویدئوی پس‌زمینه، گالری و صحنهٔ سه‌بعدی تعاملی (Three.js / WebGL).

## ✨ امکانات
- 🎬 ویدئوی پس‌زمینه در بخش Hero
- 🌀 فنجان قهوهٔ سه‌بعدی تعاملی (چرخش با درگ، زوم با اسکرول)
- 🖼 گالری تصاویر با افکت‌های hover
- 🛒 سبد خرید با اعلان (Toast)
- 📱 کاملاً ریسپانسیو و راست‌چین (فارسی)
- ✨ انیمیشن‌های اسکرول، کرسر سفارشی و مارکی طلایی
