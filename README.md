# کافه رُست ☕

سایت فروش قهوه‌ی تخصصی — ساخته‌شده با [Vite](https://vitejs.dev) و CSS خالص، راست‌چین و فارسی.

- رُست تازه، منوی دانه‌های تک‌خاستگاه، راهنمای دم‌آوری و فرم سفارش
- انیمیشن‌های اسکرول، شمارنده‌ها و طراحی واکنش‌گرا

## اجرا

```bash
npm install
npm run dev      # حالت توسعه
npm run build    # خروجی نهایی در dist/
```

## انتشار

پوشش به `main` باعث build و انتشار خودکار روی GitHub Pages می‌شود
(`.github/workflows/deploy.yml`).
